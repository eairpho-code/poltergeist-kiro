How it works

Poltergeist watches what the human does between an agent’s steps and tells the agent about it.

Watch

Every human click and drag is recorded in device points, with the role of the control underneath it.

Pair

A human click soon after an agent tap, and close to it, is read as a correction of that tap.

Explain

When corrections agree on a consistent factor, Poltergeist tells the agent its coordinates are on the wrong scale.

  • 430×932device points on the phone screen
  • 1.5×how far off the agent reads coordinates
  • 3corrections needed to name the bug
  • 5–30sthe correction window you can choose

Run it yourself

The page is one static HTML file. Clone the repo and serve the folder, or run the Python server that backs the real thing.

Clone the repository

git clone https://github.com/example/poltergeist.git

Serve the demo folder

python -m http.server --directory demo 8000

Run the checks

python demo/check_port.py && python demo/check_app.py
