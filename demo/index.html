The pairing rule

A human click within the correction window of an agent tap counts as a correction. Three corrections whose ratios agree reveal the scale bug. The real server uses a 5 second window; this page lets you choose 5, 15 or 30 seconds.

How it works

Poltergeist watches what the human does between an agent’s steps and tells the agent about it.

Watch

Every human click and drag is recorded in device points, with the role of the control underneath it.

Pair

A human click less than the correction window after an agent tap is paired with the closest earlier agent tap that is not already paired, one human click to one agent tap. There is no distance limit: distance only decides between the agent taps that are still in the window.

Explain

When corrections agree on a consistent factor, Poltergeist tells the agent its coordinates are on the wrong scale.

Run it yourself

The page is one static HTML file. Clone the repo and serve the folder, or run the Python server that backs the real thing.

Clone the repository

git clone <the address of this repository>

Serve the demo folder

python -m http.server --directory demo 8000

Run the checks

python demo/check_port.py && python demo/check_app.py
